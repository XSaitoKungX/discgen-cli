# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.5.x   | ✅        |
| 1.4.x   | ❌        |
| < 1.4   | ❌        |

Only the latest stable release (`1.5.x`) receives security updates.
Older versions are not maintained — please always update to the latest version.

---

## Reporting a Vulnerability

**Please do not report security vulnerabilities via GitHub Issues.**

If you discover a security vulnerability in `discgen-cli`, please report it responsibly:

- **Discord:** [xsaitox](https://discord.com/users/848917797501141052)
- **Support Server:** [Saito Development Hub](https://discord.gg/FNcAvF2aGQ)
- **Website:** [xsaitox.dev](https://xsaitox.dev/en)

### What to include

- A clear description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Any suggested fix (optional)

### What to expect

- **Acknowledgement** within 48 hours
- **Status update** within 7 days — whether the issue is accepted, rejected, or needs more info
- If accepted: a fix will be prioritized and a patched version released as soon as possible
- You will be credited in the release notes (unless you prefer to stay anonymous)

---

## Scope

This policy applies to the `discgen-cli` package itself and the code it generates.
Third-party dependencies are out of scope — please report those to their respective maintainers.
